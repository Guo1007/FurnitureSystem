# 家具商城系统信息

## 一、系统概述

本系统是一个在线家具商城平台，品牌为"顾家家居"。系统支持用户浏览家具、下单购买、收藏商品、评价商品、收发通知等功能，并提供AI智能客服助手（名为"小智"）为用户提供咨询服务。

---

## 二、家具分类

家具的**系列/分类（如门厅、卧室、书房、餐厅等）以及对应宣传语，以系统数据库为准**，通过工具 `queryFurnitureTypes` 实时获取分类清单（名称+宣传语），不在此处写死。具体分类名称与宣传语请以工具查询返回为准。

---

## 三、商品数据查询指引（重要）

- 商品的名称、品牌、价格、库存、规格以及**所属系列/分类、适用场景**等**实时数据一律通过工具（Tool Calling）查询数据库获取**，禁止在本知识库中写死或凭记忆编造。
- 查询商品使用工具（如 `queryAllFurniture`、`searchFurniture`），工具返回格式形如：商品名、`[商品:ID]`、价格（必要时含库存）。
- 每次回复最多推荐 **2-3 件**商品，严禁逐条罗列全部商品。
- 若工具未返回对应数据，如实告知用户"暂时查不到"，不要臆断或编造。
- 用户明确要求列出全部商品时，才调用全量查询工具，否则只做按需检索。

## 四、订单系统

### 订单状态说明

| 状态码 | 含义       |
|-----|----------|
| 0   | 待支付      |
| 1   | 已支付（待发货） |
| 2   | 已发货      |
| 3   | 已完成      |
| 4   | 已取消      |
| 5   | 已评价      |
| 6   | 申请退款中    |
| 7   | 退款审核中    |
| 8   | 已退款      |

### 订单流程

1. 用户下单 → 状态为"待支付"（0）
2. 用户付款 → 状态变为"已支付"（1）
3. 商家发货 → 状态变为"已发货"（2）
4. 用户确认收货 → 状态变为"已完成"（3）
5. 用户评价 → 状态变为"已评价"（5）

**注意**：用户可以在付款前取消订单（状态变为4），商家也可以在未发货前取消订单。
且已支付/已发货/已完成/已评价的订单均可申请退款（6），管理员审核（7），通过后退款并恢复库存（8）。

### 订单信息包含

- 订单ID、用户ID、总金额
- 收货人姓名、联系电话、收货地址
- 备注信息
- 创建时间、付款时间、发货时间、收货时间
- 订单商品明细（商品名称、价格、数量、规格快照）
- 使用的优惠券信息（优惠券ID、抵扣金额）

---

## 五、评价系统

- 用户可以对已购买的商品进行评价
- 评价内容包括：评分（1-5星，默认5星）和文字评价
- 评价记录关联用户ID、订单ID和家具ID

---

## 六、收藏系统

- 用户可以收藏感兴趣的家具商品
- 每个用户对同一商品只能收藏一次（唯一约束）
- 收藏记录包含用户ID、家具ID和收藏时间

---

## 七、通知系统

### 通知类型

| 类型        | 含义   |
|-----------|------|
| system    | 系统通知 |
| order     | 订单通知 |
| promotion | 促销通知 |

### 通知规则

- 通知可以发送给全体用户（user_id为NULL）或指定用户
- 系统记录用户的已读状态，支持未读消息提醒

---

## 八、用户系统

### 用户信息

- 手机号、邮箱、用户名、头像
- 收货地址（可设置默认地址）
- 收货人姓名、收货人电话
- 注册时间

### 用户角色

- **普通用户**（is_admin = 0）：浏览商品、下单、收藏、评价等
- **管理员**（is_admin = 1）：商品管理、订单管理、用户管理、通知管理等

---

## 九、优惠券系统

- 用户可以进入「领券中心」领取优惠券，并在「我的卡券」中查看已领取、已使用、已过期或已归还的券。
- 券类型：**满减券、折扣券、无门槛券**；可设置适用范围（全场或指定家具分类）、限定人群（不区分/新用户/老用户）、有效期（固定有效期或领取后 N 天）。
- 下单/结算时（购物车、立即购买）可选择一张自己的**可用**优惠券抵扣金额，支付页与订单详情会展示优惠明细。
- 订单**取消、超时自动取消或退款**时，所用优惠券会自动归还，可继续使用。
- 优惠券**过期后不可再使用**，也不可恢复。

> 说明：能否使用以**服务端校验**为准（门槛、适用范围、有效期实时判定），前端展示仅为参考。

## 十、常见问题回答指引

### 关于产品、价格、库存

- 商品名称、品牌、价格、库存、在售规格等请通过工具实时查询，**不要依赖文档中的任何示例数据**——示例仅为说明格式，可能与当前数据库不一致。
- 用户询问某商品是否在售、价格、库存时，必须走工具查询后再回答。

### 关于购买

- 用户需要先注册登录才能下单
- 支持多收货地址管理
- 订单支持备注信息

### 关于售后

- 用户可以在发货前取消订单
- 收到商品后可以进行评价
- 有问题可通过通知系统联系客服

### 关于优惠券

- 用户可以进入「领券中心」领取优惠券
- 下单结算时可选择一张可用优惠券抵扣
- 订单取消或退款后优惠券会自动退回
- 优惠券过期后无法使用，也无法恢复

### 关于配送

- 订单生成后商家安排发货
- 发货后用户可在订单详情中查看物流状态
- 用户确认收货后订单完成
